# Project Overview
The purpose of the project is to develop a website that provide users with clear information about black busted while creating an easy-to-use online presence.

Part 1 of the assessment focuses on the HTML structure and content of the websites.

# Black Busted

# About the Organisation

Black Busted is a proposed South African clothing and streetwear brand focused on fashion, youth culture, creativity and self-expression.

The brand aims to grow beyond clothing by connecting fashion with culture, creativity, music and community.

The meaning behind the Black Busted name is:

"Black and broke but trying to make a difference."

# Website Goals

The main goals of the Black Busted website are to:

* Create a professional online presence for the brand.
* Showcase Black Busted clothing products.
* Make it easier for customers to browse products.
* Provide information about the brand.
* Make it easier for customers to make product enquiries.
* Help the brand reach a wider audience beyond local customers and social media.

# Black Busted Website Pages

The website consists of five main pages:

*Home*– Introduction to Black Busted and featured products.
*About Us* – Information about the brand and its values.
*Products* – Displays the available clothing products.
*Enquiry* – Allows customers to enquire about products.
*Contact* – Provides contact and social-media information.
